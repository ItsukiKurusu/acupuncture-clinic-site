夕方になると靴がきつい、足先が一年中冷たい、ふくらはぎが重だるい。冷えとむくみは別々の悩みのようでいて、どちらも「巡りが滞っている」という同じ土台の上に起きています。冷えれば血管が縮んで流れが落ち、流れが落ちればさらに冷える、という繰り返しです。

この記事でご紹介する6つのツボは、いずれも足の内側からひざの内側にかけて集まっています。入浴後に足を組んで座れば、6か所すべてを数分でケアできる並びです。

---

## ツボを押す前に｜共通の基本

- **強さ**：「痛気持ちいい」と感じるところまで。強く押し込むほど効くわけではありません
- **時間と回数**：5秒押してゆるめる、を左右2〜3回ずつ
- **呼吸**：止めないこと。息を吐きながら押すと力が抜けやすくなります
- **タイミング**：入浴後や就寝前など、体が温まっている時間帯がおすすめです

**妊娠中の方へ**：この記事で紹介するツボのうち、三陰交・血海をはじめとする足の内側のツボは、妊娠中は刺激を控えることとされています。必ず事前に主治医または専門家にご相談ください。

また、次のようなときは行わないでください。

- 足に強い腫れ・熱感・赤みがあるとき（片脚だけ急に腫れた場合は受診をご検討ください）
- 皮膚に傷や炎症があるとき
- 発熱しているとき

## 1. 三陰交（さんいんこう）

<video controls playsinline preload="metadata" src="/saninkou.mp4"></video>

**位置**

内くるぶしの一番高いところから、指4本分上。すねの骨（脛骨）の内側をなぞっていくと、少しくぼんだところが見つかります。

**使われる理由**

名前のとおり、足を通る3本の陰の経絡——脾経・肝経・腎経——が交わる場所とされてきました。1か所で3つの経絡に働きかけられると考えられているため、東洋医学では冷え・むくみ・女性の不調に対する代表的なツボとして扱われます。

冷えと血行不良が背景にある不調に、幅広く使われるツボです。

**こんな方に**

- 足先の冷えが慢性的にある
- 下半身がむくみやすい
- 生理前後に不調が出やすい

**押し方**

リラックスした姿勢で座り、痛気持ちいい強さで5秒押してゆるめる。左右2〜3回繰り返します。

**注意**

妊娠中の方は刺激を控えてください。

## 2. 陰陵泉（いんりょうせん）

<video controls playsinline preload="metadata" src="/inryousen.mp4"></video>

**位置**

ひざの内側。すねの骨の内側を下から上へなぞっていくと、ひざの下あたりで指が止まるくぼみがあります。押すと「ズーン」と響く感覚がある場所が目印です。

**使われる理由**

足太陰脾経の合穴にあたります。東洋医学では、脾は水分の巡りをつかさどると考えられており、陰陵泉は体にたまった余分な水分（湿）を流すツボとして位置づけられてきました。

「雨の日や湿度の高い日に体が重くなる」という方に選ばれることの多いツボです。福岡は梅雨時期の湿度が高く、この時期に不調を訴える方は少なくありません。

**こんな方に**

- 足のむくみが強い
- 下半身が重だるい
- 天気が崩れる前に不調が出る

**押し方**

痛気持ちいい強さで5秒押してゆるめる。左右2〜3回。

**注意**

強く押しすぎると内側の筋肉や皮膚を痛めることがあります。

## 3. 太谿（たいけい）

<video controls playsinline preload="metadata" src="/taikei.mp4"></video>

**位置**

内くるぶしとアキレス腱の間にあるくぼみ。指を当てると、拍動を感じられることがあります。

**使われる理由**

足少陰腎経の原穴です。東洋医学における腎は、体を温める力や生命エネルギーの源とされ、その気が最もあらわれる場所が原穴だと考えられてきました。冷えや疲れやすさが続くときに、まず選ばれるツボのひとつです。

拍動を感じられることからも分かるように、足先へ向かう血流の通り道に近い位置にあります。

**こんな方に**

- 体の芯から冷える感じがある
- 疲れが抜けにくい
- 足首から先が冷たい

**押し方**

親指でゆっくり押し、痛気持ちいい強さで5秒程度。左右2〜3回、深呼吸しながら。

**注意**

強い圧をかけすぎないように。拍動の上を強く押さえ続けないでください。

## 4. 復溜（ふくりゅう）

<video controls playsinline preload="metadata" src="/hukuryu.mp4"></video>

**位置**

太谿から指2〜3本分ほど上、アキレス腱の内側寄りにあります。太谿を見つけてから上へたどるのが確実です。

**使われる理由**

太谿と同じ足少陰腎経のツボで、東洋医学では体内の水分バランスを調整する働きがあると考えられてきました。「汗をかきすぎる」「逆に汗をかけない」という、どちらの方向のお悩みにも用いられる点が特徴です。

むくみに対しては、太谿とセットで押すとケアしやすい並びになっています。

**こんな方に**

- 足のむくみとだるさが同時にある
- 汗のかき方が偏っている自覚がある
- 冷えとむくみを両方感じる

**押し方**

親指でゆっくり押す。痛気持ちいい強さで5秒、左右2〜3回。

**注意**

強く押しすぎないように。痛みが強い日は控えめに。

---

## 5. 太白（たいはく）

<video controls playsinline preload="metadata" src="/taihaku.mp4"></video>

**位置**

足の内側、親指の付け根の骨の後ろ側。土踏まずの少し上、足の側面で色の境目あたりに沿ってたどると見つかります。

**使われる理由**

足太陰脾経の原穴です。脾は消化と水分代謝の両方に関わると考えられているため、太白は「胃腸の調子」と「むくみ・冷え」の両方に用いられます。

食が細い、食べると体が重くなる、といった消化の負担が冷えにつながっているタイプの方に選ばれます。

**こんな方に**

- 冷えとともに胃もたれがある
- 食欲が安定しない
- 体が重だるく、水分がたまりやすい

**押し方**

痛気持ちいい強さで5秒程度、左右2〜3回。深呼吸しながらゆっくりと。

**注意**

足裏や足の側面は皮膚が薄い部分もあるため、爪を立てないように気をつけてください。

## 6. 血海（けっかい）

<video controls playsinline preload="metadata" src="/kekkai.mp4"></video>

**位置**

ひざのお皿の内側上方。太ももに力を入れると内側の筋肉が盛り上がるので、その膨らみの上あたりを押すと、響くポイントが見つかります。

**使われる理由**

名前に「血」を含むとおり、東洋医学では血の巡りを整えるツボとして扱われてきました。生理痛やPMS、肌の調子といった、血の巡りと関わりが深いとされる不調に用いられます。

解剖学的には、太ももの内側にある内側広筋の上に位置します。この筋肉は膝を安定させる役割を持ち、座っている時間が長いと働きが落ちやすい部位です。

**こんな方に**

- 生理痛やPMSが重い
- 冷えとともに肌の調子が気になる
- 下半身の血行不良を感じる

**押し方**

指でじんわり「痛気持ちいい」圧を5秒。左右2〜3回、深い呼吸でゆっくりほぐします。

**注意**

生理中は気持ちいい範囲で軽めに。妊娠中の方は刺激を控えてください。

## 6つのツボの使い分け

| こんなとき | おすすめ |
| --- | --- |
| 冷えと生理の不調が重なる | 三陰交・血海 |
| 足のむくみが強い、湿度で不調が出る | 陰陵泉 |
| 体の芯から冷える、疲れが抜けない | 太谿 |
| むくみとだるさが同時にある | 復溜 |
| 冷えと胃腸の重さが重なる | 太白 |

すべてを一度に押す必要はありません。足の内側を下から上へ、太白 → 太谿 → 復溜 → 三陰交 → 陰陵泉 → 血海 の順になぞるように、気になるところだけ選んでも構いません。

## セルフケアと合わせたい習慣

ツボ押しの効果を感じやすくするために、次の3つも意識してみてください。

1. **ふくらはぎを動かす**：ふくらはぎの筋肉は、足に降りた血液を心臓へ送り返すポンプの役割を担っています。1時間に一度、かかとの上げ下ろしを10回するだけでも違います
2. **湯船につかる**：シャワーだけで済ませる日が続くと、体の深部は温まりません
3. **足首を冷やさない**：足首まわりは皮膚のすぐ下を血管が通っています。夏場の冷房でも、ここを覆うだけで冷え方が変わります

## セルフケアで変わりにくい冷え・むくみには

次のような場合は、セルフケアだけでは変化を感じにくいことがあります。

- 何年も冷え性が続いている
- 夏でも足先が冷たい
- むくみが翌朝まで残る
- 生理痛が年々重くなっている

当院では、鍼とお灸で体を温めながら、冷えやむくみの背景にある自律神経の状態や姿勢まで含めて整えていきます。

自律神経の乱れからくる不調については、[自律神経の乱れの症状ページ](/symptoms/jiritsu-shinkei)で詳しくご紹介しています。
